# Benchmark reports

When working in this folder, say **"test it"** to run the relevant checks and save a report here.

The first report is `bench1.md`; subsequent reports include their sequence number and creation timestamp, such as `bench2_2026-10-07_14-30-00.md`. Every report records its creation time in Asia/Calcutta.

See [the existing agent guide](../agent.md#benchmark-requests) for the complete workflow.
